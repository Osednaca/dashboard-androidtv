- Login trusts the previous intended URL across roles. Validate same-origin intended destinations against authenticated route access and clear stale selected-business state. Direct forbidden-route authorization remains enforced.

- PWA caches only explicitly allowed public assets. Never cache authenticated HTML, Inertia responses, APIs or private media; use a public offline fallback. Cache API does not automatically honor HTTP cache headers (MDN Cache documentation), so manually reject private/no-store responses.
